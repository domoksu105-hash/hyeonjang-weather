# 나라장터 낙찰결과 일일 알림

기존 **입찰공고 브리핑**(오전 9시)과 **별개로**, 건축 분야 공사·감리·설계의
**낙찰(개찰) 결과**만 매일 따로 메일로 받아보기 위한 Google Apps Script입니다.

## 왜 Apps Script인가 (Claude 자동예약이 아니라)

나라장터 OpenAPI(`apis.data.go.kr`)는 Claude가 실행되는 클라우드 환경의
조직 방화벽 정책상 **접속이 차단**됩니다. 반면 기존 입찰공고 브리핑이 잘 되는 이유는
그게 **Google 서버(Apps Script)** 에서 돌기 때문입니다. 그래서 낙찰결과도
**같은 방식(Apps Script)** 으로 만드는 것이 가장 안정적이고 무료입니다.

## 설치 방법

1. https://script.google.com 접속 → 기존 "입찰공고" 프로젝트를 열거나 **새 프로젝트** 생성
2. `낙찰결과-알림.gs` 내용을 붙여넣기
   - 새 프로젝트로 만들면 파일 하나에 전체를 넣으면 됩니다.
   - 기존 프로젝트에 **파일을 추가**해서 넣어도 됩니다. (단, `SERVICE_KEY` 등
     전역변수 이름이 기존 파일과 겹치므로, **별도 프로젝트로 분리**하는 것을 권장)
3. 상단 함수 선택에서 **`pingScsbid`** 실행 → `보기 > 실행 로그`에서
   - `[200]` 과 `"resultCode":"00"` 이 보이면 정상
   - 로그에 찍힌 실제 필드명(낙찰업체·낙찰금액·낙찰률)이 스크립트의 후보키와
     다르면 알려주세요. (컬럼이 `-` 로 비면 이 경우)
4. **`sendScsbidDigest`** 실행 → 권한 승인 후 테스트 메일 도착 확인
5. **`setupScsbidTrigger`** 실행 → 매일 자동발송 등록 (기본 오후 6시)

## 설정값 (파일 상단)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `SERVICE_KEY` | (기존과 동일) | 공공데이터포털 일반 인증키(Decoding) |
| `RECIPIENT` | `domoksu105@gmail.com` | 받을 이메일 |
| `SEND_HOUR` | `18` | 매일 발송 시각(24h). 오전으로 바꾸려면 `9` 등으로 수정 |
| `LOOKBACK_HOURS` | `26` | 조회 창(시간). 최근 N시간 등록된 낙찰분 |
| `INQRY_DIV` | `1` | 낙찰정보 등록일시 기준(확정값). 날짜는 12자리(YYYYMMDDHHmm) 필수 |

## 확정된 API 스펙 (검증 완료)

- End Point: `https://apis.data.go.kr/1230000/as/ScsbidInfoService`
- 오퍼레이션: `getScsbidListSttusCnstwk`(공사 낙찰현황) / `getScsbidListSttusServc`(용역 낙찰현황)
- 파라미터: `inqryDiv=1`, `inqryBgnDt`/`inqryEndDt`=YYYYMMDDHHmm(12자리), `type=json`
- 응답 필드: `bidwinnrNm`(낙찰업체) · `sucsfbidAmt`(낙찰금액) · `sucsfbidRate`(낙찰률) ·
  `rlOpengDt`(실개찰일시) · `dminsttNm`(수요기관) · `bidNtceNm`(공고명)

## 대상 범위

- **금액 조건 없음** — 건축 분야만 필터 (공고 브리핑과 달리 30억/1.5억 문턱 없음)
- ① 공사 낙찰(건축) ② 감리·건설사업관리 낙찰(건축) ③ 설계용역 낙찰(건축)
- 건축 판별: `DOMAIN_INCLUDE`(건축·신축·청사·학교·병원 등) 포함 &
  `DOMAIN_EXCLUDE`(전기·소방·통신·전산 등) 제외 — 기존 입찰공고 스크립트와 동일 기준

## 참고

- 낙찰정보서비스: 조달청_나라장터 낙찰정보서비스 (공공데이터포털 15129397)
- 개찰결과는 공고당 여러 순위 행이 오므로 **1순위(낙찰예정자)** 만 추립니다.
- 낙찰업체/금액/낙찰률 필드명은 서비스 버전마다 달라, 여러 후보키를 자동 탐색합니다.
  `pingScsbid` 로그로 실제 응답을 확인하면 컬럼 매핑을 확정할 수 있습니다.
